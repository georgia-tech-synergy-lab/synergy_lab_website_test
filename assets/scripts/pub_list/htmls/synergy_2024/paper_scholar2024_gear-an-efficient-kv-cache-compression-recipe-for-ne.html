Gear: An efficient kv cache compression recipe for near-lossless generative inference of llm
    Hao Kang, Qingru Zhang, Souvik Kundu, Geonhwa Jeong, Zaoxing Liu, Tushar Krishna, Tuo Zhao arXiv preprint arXiv:2403.05527
    Abstract Paper
    llm quantization algorithms

    Abstract

    GEAR proposes a near-lossless KV cache compression method for efficient LLM inference by combining quantization, low-rank error approximation, and sparse outlier correction.
