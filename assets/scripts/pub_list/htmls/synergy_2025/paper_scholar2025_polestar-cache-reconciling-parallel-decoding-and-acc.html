Polestar-cache: Reconciling parallel decoding and accuracy in diffusion LLMs via token drift-aware KV cache recalibration
    Mingyu Lee, Akshat Ramachandran, Souvik Kundu, Tushar Krishna Workshop on Latent {\&} Implicit Thinking {\textendash} Going Beyond CoT Reasoning
    Abstract Paper
    llm ai memoryauthentication systems

    Abstract

    Polestar-Cache is a drift-aware KV caching framework for diffusion LLMs that improves accuracy and parallel decoding by selectively refreshing misaligned cache entries.
