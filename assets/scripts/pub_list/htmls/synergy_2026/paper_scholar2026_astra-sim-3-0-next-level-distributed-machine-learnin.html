ASTRA-sim 3.0: Next-Level Distributed Machine Learning Simulations via High-Fidelity GPU and Infrastructure Modeling

    Abstract

    Presents ASTRA-sim 3.0, a high-fidelity distributed ML simulator with cache-line granularity GPU execution modeling and an infrastructure representation (InfraGraph) to enable design space exploration for collective algorithms and network requirements.
