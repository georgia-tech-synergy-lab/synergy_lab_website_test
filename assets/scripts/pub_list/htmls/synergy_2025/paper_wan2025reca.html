    Abstract

    Cooperative embodied systems—where multiple agents collaborate through integrated perception, planning, action, and advanced reasoning powered by large language models (LLMs)—hold great potential for tackling complex, long-horizon, and multi-objective tasks in real-world environments. Despite rapid algorithmic progress, deploying embodied agents on current systems remains challenging due to prolonged planning and communication latency, limited scalability, and heightened sensitivity in low-level execution—all contributing to significant system inefficiencies. This work introduces ReCA, a characterization and co-design framework dedicated to accelerating cooperative embodied agent systems, with the goal of enhancing both task efficiency and system scalability. On the algorithm level, ReCA enables efficient local model processing to mitigate substantial model computation costs. On the system level, it introduces a dual-memory structure integrating long-term and short-term memory, a hierarchical cooperative planning scheme supporting both centralized and decentralized collaboration, and a planning-guided multi-step execution mechanism for highly efficient and scalable cooperative computation. On the hardware level, ReCA employs a heterogeneous hardware architecture that couples a high-level planning GPU subsystem with a low-level planning accelerator subsystem to ensure robust and efficient task execution. Evaluated across long-horizon, multi-objective tasks, ReCA generalizes across diverse application scenarios and system scales, achieving a 4.3% increase in mission success rate and a 10.2× speedup compared to state-of-the-art cooperative embodied autonomous agent systems.
