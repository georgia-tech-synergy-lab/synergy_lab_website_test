OneDSE: A Unified Microprocessor Metric Prediction and Design Space Exploration Framework
    Ritik Raj, Akshat Ramachandran, Jeff Nye, Shashank Nemawarkar, Tushar Krishna arXiv preprint arXiv:2505.03771
    Abstract Paper
    algorithms simulation mlhw

    Abstract

    OneDSE introduces a unified metric-prediction and design-space-exploration framework for CPU architecture using transformer-based estimation and a fast optimization strategy with ML-enhanced search.
