Flexinfer: Flexible llm inference with cpu computations
    Seonjin Na, Geonhwa Jeong, Byung H Ahn, Aaron Jezghani, Jeffrey Young, Christopher J Hughes, Tushar Krishna, Hyesoon Kim Proceedings of Machine Learning and Systems
    Abstract Paper
    systems llm simulation

    Abstract

    FlexInfer improves CPU-based offloading LLM inference by using a performance estimator to dynamically choose execution policies for prefill and decode to cut end-to-end latency.
