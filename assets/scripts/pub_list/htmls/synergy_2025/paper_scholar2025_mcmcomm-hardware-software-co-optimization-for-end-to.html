MCMComm: Hardware-Software Co-Optimization for End-to-End Communication in Multi-Chip-Modules
    Ritik Raj, Shengjie Lin, William Won, Tushar Krishna arXiv preprint arXiv:2505.00041
    Abstract Paper
    systems algorithms distributed

    Abstract

    Presents a hardware-software co-optimization framework for end-to-end, congestion-aware communication in multi-chip-module accelerators, using metaheuristics and MIQP to improve CNN and Vision Transformer performance.
