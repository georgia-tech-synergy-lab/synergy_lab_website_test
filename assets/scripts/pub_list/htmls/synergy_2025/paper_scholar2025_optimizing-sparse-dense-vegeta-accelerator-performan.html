Optimizing Sparse/Dense VEGETA Accelerator Performance with Microscaling Quantization
    Kazi Barria Nine, Connor Talley, Ajay Sharma Mandadi, Tushar Krishna, Arijit Raychowdhury 2025 IEEE International Symposium on Circuits and Systems (ISCAS)
    Abstract Paper
    quantization accelerators sparsity

    Abstract

    Presents an optimized sparse/dense VEGETA systolic-array accelerator using microscaling quantization (MX) with dedicated scale-factor buffers and modified MXFP compute to improve performance and mitigate the memory wall.
