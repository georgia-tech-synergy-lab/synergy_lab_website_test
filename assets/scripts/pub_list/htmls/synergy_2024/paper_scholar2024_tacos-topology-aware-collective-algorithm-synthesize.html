Tacos: Topology-aware collective algorithm synthesizer for distributed machine learning
    William Won, Midhilesh Elavazhagan, Sudarshan Srinivasan, Swati Gupta, Tushar Krishna 2024 57th IEEE/ACM International Symposium on Microarchitecture (MICRO)
    Abstract Paper
    distributed algorithms ai

    Abstract

    Presents Tacos, a topology-aware synthesizer that generates efficient collective communication algorithms to reduce network overhead for distributed machine learning.
