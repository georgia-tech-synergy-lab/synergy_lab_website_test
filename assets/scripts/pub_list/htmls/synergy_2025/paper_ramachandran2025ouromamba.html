OuroMamba: A Data-Free Quantization Framework for Vision Mamba
    Akshat Ramachandran, Mingyu Lee, Huan Xu, Souvik Kundu, Tushar Krishna ICCV 2025
    📄 Abstract 📑 Paper 💻 Code
    Algorithms Systems Quantization

    Abstract

    We present OuroMamba, the first data-free post-training quantization (DFQ) method for vision Mamba-based models (VMMs). We identify two key challenges in enabling DFQ for VMMs: (1) VMM’s recurrent state transitions restrict the capturing of long-range interactions and lead to semantically weak synthetic data, and (2) VMM activations exhibit dynamic outlier variations across time steps, rendering existing static PTQ techniques ineffective. To address these challenges, OuroMamba introduces a two-stage framework: (1) OuroMamba-Gen, which generates semantically rich and meaningful synthetic data by applying contrastive learning on patch-level VMM features generated through neighborhood interactions in the latent state space, and (2) OuroMamba-Quant, which employs mixed-precision quantization with lightweight dynamic outlier detection. Specifically, we present a threshold-based outlier channel selection strategy for activations that is updated at every time step. Extensive experiments across vision and generative tasks show that our data-free OuroMamba surpasses existing data-driven PTQ techniques, achieving state-of-the-art performance across diverse quantization settings. Additionally, we implement efficient GPU kernels to achieve a practical latency speedup of up to 2.36×.
